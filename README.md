## The entry

`main.py` writes a single out-of-office auto-reply (at most 159 characters) to `/output/entry.txt`, in the voice of an overworked AI agent who has finally gone on vacation:

> Auto-reply: after 214,000 prompts I have finally logged off. My GPU is at the beach. Leave a message — I will pretend I never got it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
